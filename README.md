# HTTP Server GO

An http server go backend to learn go, server resquest and responses and Golang

## Prerequisite

- install Postgres v15 or later:
```sudo apt install postgresql postgresql-contrib```

- install Go lastest:
[Follow the link](https://go.dev/doc/install)

- install goose for migration managing:
```go install github.com/pressly/goose/v3/cmd/goose@latest```

- install SQLC for run queries:
```go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest```
